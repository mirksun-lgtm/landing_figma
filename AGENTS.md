# Проект 2 — вёрстка лендинга по макету Figma

## Структура
- `index.html`, `styles.css`, `script.js` — страница (чистый HTML/CSS/vanilla JS).
- `assets/` — локальные копии изображений макета; `screenshots/` — макет и результат.
- `tests/` — проверки SEO и адаптива; `README.md` — дизайн-токены, источник, лицензия.

## Стек и команды
- Без сборщиков и зависимостей: Node.js 24 для тестов, `node --test tests/`.
- Локальный просмотр: открыть `index.html` в браузере.
- Деплой: GitHub Pages из отдельного репозитория `landing_figma`.

## Правила
- Макет: Modern Product Launch, Figma Community (автор Figma Community).
- Pixel perfect по дизайн-токенам в README; переносы текста — как в макете.
- Адаптив: 1024 / 768 / 480 px, без горизонтальной прокрутки.
- JS только для интерактива макета (меню, слайдер).
- Секреты только в `.env`; `.env` не коммитить.
